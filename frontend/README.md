# Фронтенд «Чудо Обувь»

Простой интерфейс на React + TypeScript + Vite для уже запущенного FastAPI API.

## Запуск

Требуется Node.js 20+.

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`). API по умолчанию должен работать на `http://127.0.0.1:8000`. Если адрес отличается, поменяйте `VITE_API_URL` в `.env`.

## Страницы и права

- `login` — вход только по логину из таблицы `users`, без пароля. Отсюда можно открыть каталог без входа.
- `main` — доступен и без авторизации для просмотра каталога; после входа доступны поиск по названию/описанию, фильтр по категории и подкатегории, сортировка по цене, выбор размера, корзина и оформление заказа.
- `orders` — обычный пользователь видит свои заказы; менеджер и администратор видят все заказы. Менеджер/администратор могут удалить заказ. Только администратор может менять дату заказа, количество позиции и удалять позицию заказа.
- Менеджер и администратор могут создавать, редактировать и удалять карточки товара, а также менять остатки.

Роль берётся из ответа `/api/auth/login`. Для защищённых запросов фронтенд передаёт `X-User-ID`, как требует текущий учебный API.

## Структура исходников

- `src/App.tsx` — переключение страниц, вход и сообщения об ошибках.
- `src/components/Layout.tsx` — шапка и экран входа.
- `src/pages/CatalogPage.tsx` — каталог, фильтры, корзина и редактор товаров.
- `src/pages/OrdersPage.tsx` — список заказов и управление ими.
- `src/api.ts` — запросы к backend.
- `src/styles.css` — общие стили интерфейса, сгруппированные по блокам страницы. Основные цвета вынесены в CSS-переменные в начале файла.

## Изображения

- `public/images/store-image.png` — логотип магазина (исходный файл `Чудо Обувь.png`).
- `public/images/picture.png` — заглушка для товара без изображения.
- `public/favicon.ico` — иконка вкладки браузера (исходный файл `Чудо Обувь.ico`).
- `public/images/products/` — здесь уже размещены все 31 изображения из `Images.zip`. В поле `image_path` у товара указывайте имя файла из Excel, например `IMG_KS_195217.png`. Также принимаются полные HTTP(S)-ссылки. При импорте товаров имена из столбца `Изображение` совпадают с файлами в этой папке.

## Важное ограничение текущего API

У API нет отдельного `GET /api/sizes` и нет списка пользователей. Поэтому интерфейс выбирает только размеры, которые уже возвращаются в `sizes` конкретного товара. В редакторе остатков можно указать ID размера из таблицы `sizes`, если требуется добавить сочетание товара и размера. Для входа нужно знать логин существующего пользователя.
