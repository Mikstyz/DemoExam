Вот универсальная шпаргалка по работе с виртуальным окружением Python для Bash и Fish. Сохраните её себе в проект в файл README.md или NOTE.md, чтобы она всегда была под рукой.
------------------------------
## 🚀 Шпаргалка по Python Venv (Bash vs Fish)## 1. Создание окружения (одинаково для всех)
Выполняется один раз в корневой папке проекта:

python -m venv .venv

------------------------------
## 2. Активация окружения (зависит от оболочки)

| Оболочка (Shell) | Команда активации | Как понять, что сработало? |
|---|---|---|
| Bash / Zsh | source .venv/bin/activate | В начале строки появится (.venv) |
| Fish | source .venv/bin/activate.fish | В начале строки появится (.venv) |
| Windows (CMD) | .venv\Scripts\activate.bat | В начале строки появится (.venv) |
| Windows (PowerShell) | .venv\Scripts\Activate.ps1 | В начале строки появится (.venv) |

------------------------------
## 3. Деактивация (выход из окружения)
Чтобы вернуться в обычную системную оболочку, просто введите (работает везде одинаково):

deactivate

------------------------------
## 4. 🥷 Лайфхак: Работа вообще БЕЗ активации
Если не хочется каждый раз вводить команды source, можно обращаться к окружению напрямую через путь до бинарников. Это работает в абсолютно любой оболочке:

* Установка библиотек:

.venv/bin/pip install pydantic psycopg[binary]

* Запуск вашего скрипта:

.venv/bin/python main.py


------------------------------
## 5. Сохранение и перенос зависимостей на другой ПК
Чтобы на другом компьютере не устанавливать всё вручную:

   1. На текущем ПК сохраните список библиотек в файл:

   .venv/bin/pip freeze > requirements.txt

   2. На новом ПК (после создания нового .venv) установите всё одной командой:

   .venv/bin/pip install -r requirements.txt
