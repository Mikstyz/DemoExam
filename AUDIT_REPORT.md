# Отчёт по проверке проекта

## Frontend

- Разделил большой `App.tsx` на отдельные модули: `api.ts`, `types.ts`, `utils.ts`, `components/Layout.tsx`, `pages/CatalogPage.tsx`, `pages/OrdersPage.tsx`.
- Включил проверки TypeScript `noUnusedLocals` и `noUnusedParameters`.
- Исправил сохранение состояния редактора остатков при переключении между товарами: компонент получает `key` по ID товара.
- API-клиент не добавляет `Content-Type: application/json` к `FormData`.
- Включены проверки TypeScript на неиспользуемые локальные переменные и параметры.
- Форма остатков сбрасывает внутреннее состояние при переключении товара.
- При ошибке сохранения карточки каталог обновляется, чтобы частично созданный товар не пропадал из текущего списка.

## Backend

- Маршрут `PUT /api/products/{product_id}/stock/by-value` объявлен до маршрута с `{size_id}`.
- Проверяется, что подкатегория принадлежит выбранной категории.
- Обработчики товара отклоняют пустые названия и производителя; обновление не допускает `null` для обязательных полей.
- API не принимает размер, состоящий только из пробелов.
- PATCH подкатегории корректно отклоняет `null` в обязательных полях.
- Удаление заказа или его позиции больше не проходит молча, если отсутствует складская запись, в которую нужно вернуть остаток.
- Удалён неиспользуемый импорт из `api/products.py`.
- Настройки API и скриптов читаются из одного `backend/config.toml`.

## Автоматические проверки

- TypeScript: `tsc --noEmit --noUnusedLocals --noUnusedParameters`.
- Production-сборка Vite.
- Синтаксис Python: `compileall`.
- Проверка порядка конфликтующих маршрутов.
- Проверка структуры архива и исключение `node_modules`, `dist`, `__pycache__`.

## Что не проверяется автоматически в этой среде

Нет подключения к локальной PostgreSQL пользователя, поэтому нельзя подтвердить интеграционные сценарии с его базой: вход, права ролей, импорт Excel, изменение остатков и полный цикл заказа. Их необходимо проверить вручную после запуска проекта. Авторизация через `X-User-ID` предназначена только для учебного проекта и не защищает API от подмены ID.
